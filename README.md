# Partenariat Église PWA

Application installable depuis le navigateur pour suivre les paiements mensuels d’un partenariat.

## Fonctions
- Montant mensuel modifiable
- Nom du membre
- Logo de l’église
- Photo du membre
- Couleurs personnalisables
- Paiement mois par mois
- Mode de paiement : Mobile Money ou Espèce
- Date de paiement automatique
- Reçu imprimable
- Installation sur téléphone depuis le navigateur

## Mise en ligne simple avec Vercel
1. Créer un compte sur https://vercel.com
2. Créer un compte GitHub
3. Mettre ce dossier sur GitHub
4. Dans Vercel : Add New Project
5. Importer le projet GitHub
6. Cliquer sur Deploy
7. Copier le lien obtenu et le partager aux membres

## Installation sur téléphone
Sur Android avec Chrome :
1. Ouvrir le lien de l’application
2. Cliquer sur les trois points
3. Choisir “Ajouter à l’écran d’accueil”
